# Getting help

Start with the [Quick install](README.MD#quick-install),
[troubleshooting guide](README.MD#troubleshooting), and the shipped
[configuration presets](CONFIG_PRESETS.md). They answer most deployment and
performance questions.

For a bug report, use the GitHub issue forms and include a redacted client log,
XDNS version, platform, selected transport, and the smallest configuration
that reproduces the problem. Never publish `encrypt_key.txt`, real tunnel
domains, server IP addresses, or resolver lists that could put users at risk.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) rather than
opening a public issue.
